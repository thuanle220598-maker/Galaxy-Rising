**Goal:** Replace the current geometric Crimson Gale with a smooth, layered, multi-color pixel-art attack and establish the production pattern for the rest of Fire God's effects.

**Architecture:** Keep combat timing authoritative in `CombatPrototype` and reuse `PrototypeFireVfx` for sprite playback. Extend the existing generator, importer and animator only where layered presentation requires it, then expose one composition entry point so gameplay code does not manage individual VFX layers.
